## Findings during this audit

| Finding | Status |
|---|---|
| No WebGL: `new THREE.WebGLRenderer` threw and the page stayed blank | Fixed v47: readable message (`#nogl`) |
| No loading feedback during the multi-second synchronous world build | Fixed v47: `#boot` screen, removed on the first frame |
| Uncaught errors were invisible to players | Fixed v47: `#errBan` (max 3 distinct messages) |
| WebGL context loss: three r128 restores its state, but the game kept simulating with nothing drawn | Fixed v47: pause + message, resume on restore. Headless Chromium (SwiftShader) loses and restores the context once at startup; the game recovers (seen in every run) |
| Every Node test and tool finds the game script with `/<script>\n/`: any new head script starting that way breaks ~45 scripts silently | Guarded v47: `tools/check.py` "game script extractable" check, plus a comment in `01_head.html` |
| No traffic-density setting for weak devices | Added v47 |
| "Low" quality did not reduce the pixel count (fixed 1920x1080 buffer) | v47: Low renders 1280x720 |
| No asset manifest with licence fields; no validator | Added v47: `assets/manifests/`, `scripts/validate-assets.js` |
| Broken or obsolete test scripts (`val`, `csv_test`, `cs_check`, `gen_fit`, `h18`, `llchk`, `dups`; `dc`/`ui2`/`fx` hard-code `new.html`) | Pre-existing, listed in CLAUDE.md. Kept (history), not run |
| Stray screenshots in the repo root (`d_*.png`, `m_*.png`, …) | Git-ignored outputs of the older Playwright scripts; harmless |
| `npm audit` in `app/`: 3 moderate issues (`uuid` < 11.1.1 via `xcode` via `@capacitor/cli`) | Build-time CLI only, never shipped in the app. The only fix offered is `--force` to a different CLI line, so it is left as is (re-check on the next Capacitor update) |
