# Asset sources and licences

Last updated 2026-10-19 (v47). This describes the assets the game **actually ships today** and the rules for adding new ones.
The machine-readable version is `assets/manifests/*.json` (generated by `node tools/gen_asset_manifests.js dist/irbid-drive.html`,
checked by `node scripts/validate-assets.js`). The older per-topic files remain the detailed records: `DATA_SOURCES_AND_LICENCES.md`
(map data), `manifest/cars.json`, `manifest/photos.json` (reference photos, not shipped), `manifest/car_model_candidates.json` (Sketchfab
search results, nothing downloaded).

Every entry records: id, category, name, source URL, creator, licence name and URL, required attribution, original filename, local file,
format, size, SHA-256, commercial use, modification, redistribution, verified, performance tier and known restrictions.
`validate-assets.js` fails when a file is missing, its size or hash changed without regenerating the manifest, a third-party entry lacks a
licence or source URL, or the build loses the OSM attribution.

## Rules for adding an asset (vehicle, sound, texture, model)

1. Open the asset's own page and record the exact licence, author, URL and date in `assets/manifests/` (add a manual entry with
   `"verified": false` until the licence is checked, which the validator reports as a warning).
2. Usable licences: **CC0, CC BY, CC BY-SA** (BY-SA makes derived assets share-alike), MIT or similar, or a licence the owner has bought.
   **Not usable:** NC (non-commercial), ND (no derivatives, since conversion and LOD count as modification), Editorial, ripped game assets, and
   anything that needs an account the owner has not provided.
3. Branded cars: a licence for the 3D file does not license the brand's trademarks or design. Use a clearly generic vehicle unless the
   owner decides otherwise.
4. Budget for a browser: hero car ≤ 60k triangles and ≤ 4 MB, traffic ≤ 8k triangles. Use glTF/GLB (`GLTFLoader` r128). Each extra file means
   either inlining it as base64 (single-file rule) or changing the deployment, which is an owner decision (`PLAN.md`).
5. Never bulk-download, bypass a download gate or use an API against its terms.

## Vehicle candidate evaluation checklist

For each candidate, record: visual quality, triangles, materials, textures (count and size), GLB size, separate wheel meshes with pivots at
the hub, steering-wheel node, interior (none, low or full), damage suitability (separate panels), LODs, licence and attribution, trademark
status, and the browser cost estimate. Reject anything that fails the licence rules before judging quality.
